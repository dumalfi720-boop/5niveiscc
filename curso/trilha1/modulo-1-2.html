🚀 Cheat Code: seu primeiro Projeto

Esse é o único módulo que precisa ser feito antes de passar pro Nível 2. Projetos são a "espinha dorsal" do N2 — tudo o que vem depois usa essa base.

1

🦴 Por que Projeto é a espinha do N2

Projeto é um espaço dentro do Claude com 3 ingredientes que mudam tudo: instrução fixa (system prompt sobre quem você é e como Claude deve responder), base de conhecimento (PDFs, docs, exemplos), e histórico (todas as conversas no projeto ficam acessíveis).

O resultado prático: você abre uma conversa nova segunda-feira e diz "qual foi a decisão que tomamos sobre o lançamento Q2?" — e Claude responde, cita a conversa, e continua dali. Não é mais ferramenta sem estado. É continuidade.

💡 Por isso é o cheat code: uma única configuração de 10 minutos destranca todas as 6 features do Nível 2. Sem isso, você fica preso no chat puro pra sempre.

2

🎯 Escolhendo o tema certo

O primeiro projeto define se você vai ter "uau" ou "tanto faz". Use os 3 critérios:

1. Recorrente

Algo que você toca toda semana — atendimento de cliente, criação de conteúdo, estudo de um tema, gestão de um produto.

2. Com material de referência

Você tem PDFs, docs, exemplos passados, brand guidelines, FAQs — algo pra "alimentar" o projeto.

3. Com público/escopo definido

"Atendimento da loja X" > "Atendimento ao cliente". Específico ganha sempre.

📋 Exemplos práticos por papel:

  • • Criador de conteúdo: "Roteiros pro canal X sobre tema Y"
  • • Atendimento: "Suporte da loja Z, política W"
  • • Vendas: "Outbound pra ICP X, oferta Y"
  • • Estudo: "Concurso da carreira X, edital atual"
  • • Gestão: "Squad X, sprint atual"
3

🧬 Anatomia de um Projeto bem montado

Camada 1 — System prompt (instrução fixa)

Onde: aba "Instructions" do projeto. Tamanho: até 1 página. O que vai aí:

  • • Quem você é (papel, contexto profissional)
  • • Como Claude deve responder (tom, idioma, formato preferido)
  • • Regras fixas ("sempre cite a fonte", "nunca use jargão")
  • • Atalhos ("quando eu disser 'modo briefing', faça X")

Camada 2 — Knowledge base

Onde: "Project knowledge". Cole PDFs, docs Markdown, exemplos de trabalhos passados, brand book. Limite ~200k tokens. Comece com 2-5 arquivos essenciais — mais é menos quando o assunto é projeto novo.

Camada 3 — Histórico de conversas

Toda conversa criada dentro do projeto fica acessível. Memory ativa permite que Claude lembre decisões. Combine com "busca em conversas anteriores" (paid) pra encontrar qualquer coisa.

4

📝 Template de instrução fixa

Cole, adapte os campos entre [colchetes], pronto:

**Quem sou eu** Sou [seu papel] na [contexto / empresa]. Meu público é [quem consome o que você produz]. **Como você deve responder** - Idioma: português do Brasil, tom [confiante / informal / técnico] - Formato preferido: [bullets / parágrafos curtos / tabelas] - Sempre: [3 regras inegociáveis] - Nunca: [3 vetos claros] **Materiais de referência** Use os arquivos do projeto como fonte primária. Cite trecho ou nome do arquivo sempre que afirmar algo. **Atalhos** - Quando eu disser "modo briefing", entregue resumo executivo em 5 bullets. - Quando eu disser "modo crítico", aponte os 3 pontos fracos antes de elogiar. - Quando eu disser "modo entregável", responda em formato pronto pra cliente.
5

✅ Sinais de que você está pronto pra subir

Você criou o projeto, usou por uma semana, e começou a sentir esses incômodos. Cada um deles é gatilho do N2:

  • • "Queria que ele pegasse esse arquivo do Drive sozinho" → conectores (N2)
  • • "Esse Excel mereceria um deck" → criação de arquivos (N2)
  • • "Quero compartilhar essa ferramenta com o time" → artifacts publicáveis (N2)
  • • "Esse gráfico ficaria melhor visual" → visuais inline (N2)
  • • "Sempre pergunto pelas mesmas decisões antigas" → memória + busca (N2)
6

📋 Checklist de transição → Nível 2

Marque cada item antes de pular pra Trilha 2:

  • ☐ Tema escolhido (recorrente, com material, com escopo)
  • ☐ Instrução fixa escrita usando o template
  • ☐ 2-5 arquivos de referência anexados
  • ☐ 1 conversa-piloto rodou e o resultado foi melhor que no chat puro
  • ☐ Você revisou os erros do Claude e ajustou a instrução
  • ☐ Memory ativada nas configurações
  • ☐ Você sente atrito de manualizar (= sinal verde pra N2)

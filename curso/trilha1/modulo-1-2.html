MODULE 1.2 · CHEAT CODE · ~20 min

🚀 Cheat Code: your first Project

This is the only module that needs to be done before moving to Level 2. Projects are the "backbone" of N2 — everything that comes after uses this base.

1

🦴 Why Project is the backbone of N2

Project is a space within Claude with 3 ingredients that change everything:fixed instruction(system prompt about who you are and how Claude should respond),knowledge base(PDFs, docs, examples), andhistory(all conversations in the project are accessible).

The practical result: you open a new conversation on Monday and say "what was the decision we made about the Q2 launch?" — and Claude responds, quotes the conversation, and continues from there. It is no longer a stateless tool. It's continuity.

💡 That's why the cheat code:a single 10-minute setup unlocks all 6 Level 2 features. Without this, you're stuck in pure chat forever.

2

🎯 Choosing the right theme

The first project defines whether you will have "wow" or "whatever". Use the 3 criteria:

1. Appellant

Something you touch every week — customer service, content creation, studying a topic, managing a product.

2. With reference material

You have PDFs, docs, past examples, brand guidelines, FAQs — something to “feed” the project.

3. With defined audience/scope

"Store X service" > "Customer service". Specific always wins.

📋 Practical examples per paper:

  • • Content creator:"Scripts for channel X on topic Y"
  • • Service:"Z store support, W policy"
  • • Sales:"Outbound to ICP X, offer Y"
  • • Study:"Career X competition, current notice"
  • • Management:"Squad X, current sprint"
3

🧬 Anatomy of a well-assembled Project

Layer 1 — System prompt (fixed instruction)

Where: "Instructions" tab of the project. Size: up to 1 page. What's there:

  • • Who are you(role, professional context)
  • • How should Claude respond(tone, language, preferred format)
  • • Fixed rules("always cite the source", "never use jargon")
  • • Shortcuts("when I say 'briefing mode', do X")

Layer 2 — Knowledge base

Where: "Project knowledge". Paste PDFs, Markdown docs, examples of past work, brand book. Limit ~200k tokens. Start with 2-5 essential files — more is less when it comes to a new project.

Layer 3 — Conversation history

Every conversation created within the project is accessible. Active Memory allows Claude to remember decisions. Combine with "search in previous conversations" (paid) to find anything.

4

📝 Fixed Instruction Template

Paste, adapt the fields between [brackets], that's it:

**Who am I** I am [your role] at [context/company]. My audience is [those who consume what you produce]. **How should you respond** - Language: Brazilian Portuguese, tone [confident / informal / technical] - Preferred format: [bullets / short paragraphs / tables] - Always: [3 non-negotiable rules] - Never: [3 clear vetoes] **Reference materials** Use the project files as the primary source. Cite excerpt or file name whenever you state something. **Shortcuts** - When I say "briefing mode", deliver an executive summary in 5 bullets. - When I say "critical mode", point out the 3 weak points before praising. - When I say "deliverable mode", respond in a customer-ready format.
5

✅ Signs that you are ready to move up

You created the project, used it for a week, and started to feel these discomforts. Each of them is an N2 trigger:

  • • "I wish he would get this file from Drive himself"→ connectors (N2)
  • • "This Excel would deserve a deck"→ file creation (N2)
  • • "I want to share this tool with the team"→ publishable artifacts (N2)
  • • "This graph would look better"→ inline visuals (N2)
  • • "I always ask about the same old decisions"→ memory + search (N2)
6

📋 Transition Checklist → Level 2

Check each item before jumping to Track 2:

  • ☐ Chosen theme (recurrent, with material, with scope)
  • ☐ Fixed instruction written using the template
  • ☐ 2-5 reference files attached
  • ☐ 1 pilot conversation ran and the result was better than in pure chat
  • ☐ You reviewed Claude's errors and adjusted the instruction
  • ☐ Memory activated in settings
  • ☐ You feel friction when manualizing (= green light for N2)

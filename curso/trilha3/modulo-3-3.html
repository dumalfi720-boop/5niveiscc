MODULE 3.3 · CHEAT CODE · ~25 min

🚀 Cheat Code: the repeated task will become automation

How to find the first bottleneck task of the week, automate it with co-work + skills + /schedule and start selling automation as a service (R$ 5-15k per project).

1

🔍 Find the bottleneck task of the week

The ideal task for first automation has 4 simultaneous criteria:

Appellant

Happens every week at least

Mechanics

You know the steps by heart

Clear entry

Always comes from the same source/format

Clear output

Result has a fixed format

If only one is missing, choose another. Automation on the wrong task = wasted work.

2

🎯 Accuracy matters more than friendliness

In chat and the first few modules, chatting works. From here on out, precision > flourish. Use:

  • • Explicit input schema— "I expect .csv file with columns X, Y, Z"
  • • Explicit output schema— "deliver markdown with sections A, B, C"
  • • Success criteria— "consider failure if MRR < 0 or churn > 10%"
  • • Fail-fast— "if the entrance is missing, stop and let me know before continuing"
3

🔄 When to exchange co-work for Claude Code

Co-working is friendly but less precise. Step up to Claude Code (N4) when you need:

  • • Real Git— branches, PRs, history
  • • Parallel sessions— 3-4 Claudes running at the same time
  • • Plan mode— Claude presents a plan and awaits approval
  • • Specialized sub-agents— one for testing, one for docs, one for security
  • • Custom output styles— code reviewer, no-fluff, etc.
  • • Customers paying R$25k+— expect engineering rigor
4

⚠ The 5 mistakes that stop those who stay on N3

❌ Full permission

Giving access to everything “to make it easier” — destroys trust from the first mistake.

❌ No dry-run

Run first time in production — disaster guaranteed.

❌ No log review

Don't look at what Claude did this week — silent drift.

❌ Automate creative

Tasks that need human judgment should not be automated.

❌ Charge cheap

Selling by the hour or underpricing — you are delivering 10x the value, charge for that.

5

💰 Selling automation as a service (R$5-15k/project)

Proven revenue for first sale:

  1. 1. ICP:find 5 businesses that spend 10h+/week on a mechanical task
  2. 2. Quick proof:in 1 day, create a simple version in co-work
  3. 3. Before/after:show time saved and output quality
  4. 4. Delivery:automation + simple runbook + 1h training
  5. 5. Maintenance:monthly contract (R$800-2k) for adjustments and improvements
  6. 6. Price:Charges by the amount delivered, not by the hour

💡 Thesis:"I'll save your team 8h/week. Year: 416h × R$X = R$Y. I'll charge 10% of that." It’s consultancy with deliverables.

6

📋 Transition Checklist → Level 4

  • ☐ You have 5+ skills saved and used regularly
  • ☐ 2+ weekly rituals run via /schedule
  • ☐ At least 1 actual delivery was made to the customer
  • ☐ Have you ever found yourself thinking “I wish I could git here”
  • ☐ You read code (or are willing to learn)
  • ☐ You want to run 3-4 jobs in parallel without getting in the way

5 or more marked = ready for Trail 4.

MÓDULO 3.3 · CHEAT CODE · ~25 min

🚀 Cheat Code: a tarefa repetida vai virar automação

Como achar a primeira tarefa-bottleneck da semana, automatizar com co-work + skills + /schedule e começar a vender automação como serviço (R$ 5-15k por projeto).

1

🔍 Achar a tarefa-bottleneck da semana

A tarefa ideal pra primeira automação tem 4 critérios simultâneos:

Recorrente

Acontece toda semana, no mínimo

Mecânica

Você sabe os passos de cor

Entrada clara

Vem sempre da mesma fonte/formato

Saída clara

Resultado tem formato fixo

Se uma só falta, escolha outra. Automação na tarefa errada = trabalho jogado fora.

2

🎯 Precisão importa mais que amigabilidade

No chat e nos primeiros módulos, conversar funciona. Daqui pra cima, precisão > floreio. Use:

  • • Schema de entrada explícito — "espero arquivo .csv com colunas X, Y, Z"
  • • Schema de saída explícito — "entregue markdown com seções A, B, C"
  • • Critério de sucesso — "considere falha se MRR < 0 ou churn > 10%"
  • • Fail-fast — "se entrada faltar, pare e me avise antes de seguir"
3

🔄 Quando trocar co-work por Claude Code

Co-work é amigável mas menos preciso. Suba pro Claude Code (N4) quando precisar de:

  • • Git real — branches, PRs, histórico
  • • Sessões paralelas — 3-4 Claudes rodando ao mesmo tempo
  • • Plan mode — Claude apresenta plano e espera aprovação
  • • Sub-agentes especializados — um pra testes, outro pra docs, outro pra segurança
  • • Output styles customizados — code reviewer, no-fluff, etc.
  • • Clientes pagando R$ 25k+ — esperam rigor de engenharia
4

⚠ Os 5 erros que travam quem fica no N3

❌ Permissão total

Dar acesso a tudo "pra facilitar" — destrói confiança no 1º erro.

❌ Sem dry-run

Executar de primeira em produção — desastre garantido.

❌ Sem revisão de log

Não olhar o que Claude fez na semana — drift silencioso.

❌ Automatizar criativo

Tarefas que precisam julgamento humano não devem ser automatizadas.

❌ Cobrar barato

Vendendo por hora ou subprecificando — você está entregando 10x o valor, cobre por isso.

5

💰 Vendendo automação como serviço (R$ 5-15k/projeto)

Receita comprovada pra primeira venda:

  1. 1. ICP: ache 5 negócios que gastam 10h+/semana numa tarefa mecânica
  2. 2. Prova rápida: em 1 dia, monte versão simples no co-work
  3. 3. Antes/depois: mostre tempo poupado e qualidade do output
  4. 4. Entrega: automação + runbook simples + treino de 1h
  5. 5. Manutenção: contrato mensal (R$ 800-2k) pra ajustes e melhorias
  6. 6. Preço: cobre pelo valor entregue, não por hora

💡 Tese: "Vou poupar 8h/semana da sua equipe. Ano: 416h × R$ X = R$ Y. Cobro 10% disso." É consultoria com entregável.

6

📋 Checklist de transição → Nível 4

  • ☐ Você tem 5+ skills próprias salvas e usadas regularmente
  • ☐ 2+ rituais semanais rodam via /schedule
  • ☐ Pelo menos 1 entrega real foi feita pra cliente
  • ☐ Você já se pegou pensando "queria git aqui"
  • ☐ Você lê código (ou está disposto a aprender)
  • ☐ Você quer rodar 3-4 trabalhos em paralelo, sem se atrapalharem

5 ou mais marcados = pronto pra Trilha 4.

📂 Folder structure that makes Claude become a coworker

The difference between "reliable doer Claude" and "unpredictable Claude" isn't the model — it's the organization of the folders and the ground rules.

1

🏗 The 7-folder pattern

Numbering forces Claude to "read in order" and creates clear mind map:

~/work/
├── 00_about_me/← your role, preferences, context
├── 01_templates/← protected models (NEVER edit)
├── 02_projects/← one per client/initiative
├── 03_entries/← raw files to process
├── 04_processing/← work in progress
├── 05_outputs/← final deliveries (versioned)
└── 06_file/← closed history

Each folder has a unique purpose. Claude follows the flow input → processing → output without inventing.

2

📜 Floor rules

3-5 non-negotiable rules prevent 90% of accidents. Paste at the beginning of any co-working conversation:

Ground rules (non-negotiable):

1. Read 00_about_me/ before doing any task.
2. Never edit 01_templates/. Use as a reference.
3. Always delivered in 05_outputs/ with ISO timestamp.
4. Confirm before deleting ANY files.
5. At the end, write log in 04_processando/_log.md
3

📦 Community skills and marketplace

More than 100 skills available: Anthropic officers + community. Frontend, PDF, Excel, accounting, marketing, advertising. Don't start from scratch — research, install, customize.

Where to find:Anthropic's official marketplace · GitHub (search "claude skill") · X (search "claude code skill") · Reddit r/ClaudeAI.

Security rule:read the skill markdown before installing. Check requested permissions. Prefer official sources and well-known accounts.

4

🎯 5 real examples of co-working

1. Organize downloads

"Rename everything in ~/Downloads to the pattern {year-month-type-summary}.ext. Move to subfolders by type. Don't delete anything. Summarize what changed."

2. Weekly report from spreadsheets

"Get the 3 spreadsheets in 03_entradas/. Calculate MRR, churn and LTV. Generate Excel in 05_outputs/ with executive tab + raw tabs."

3. Pre-meeting briefing

"Look at my agenda for the next 2 hours. For each meeting with a client, it generates a 1-page briefing with history, pending issues and key questions."

4. Deck from notes

"Reads 03_entradas/notas-cliente-X.md. Creates 8-slide deck in 05_outputs using 01_templates/master-empresa.pptx."

5. Service flow

"Every morning, get new tickets from Slack #support. Cross-reference them with FAQs in 01_templates. Generate draft responses in 04_processing."

5

⚠ Non-negotiable care

  • • Principle of least privilege— give only what the task needs
  • • Backup before destructive operation— always
  • • Dry-run first— ask Claude to describe without executing
  • • Mandatory logging— for later review
  • • Low-risk tasks first— trust is built
6

✅ Signs of dominance (and the ceiling)

You master N3 when:

  • • Has 5+ own skills saved
  • • Perform weekly rituals without entering new context
  • • Delivered at least 1 real job to the client via co-work
  • • Relies on letting Claude perform tasks with low monitoring

Roof:you need git, parallel sessions, plan mode, or clients paying R$25k+. That's Claude Code (N4).

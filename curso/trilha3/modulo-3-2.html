MÓDULO 3.2 · ~20 min

📂 Estrutura de pastas que faz Claude virar coworker

A diferença entre "Claude executor confiável" e "Claude imprevisível" não é o modelo — é a organização das pastas e as regras de chão.

1

🏗 O padrão de 7 pastas

Numeração obriga Claude a "ler em ordem" e cria mapa mental claro:

~/trabalho/
├── 00_sobre_mim/ ← seu papel, preferências, contexto
├── 01_templates/ ← modelos protegidos (NUNCA editar)
├── 02_projetos/ ← um por cliente/iniciativa
├── 03_entradas/ ← arquivos brutos pra processar
├── 04_processando/ ← trabalho em andamento
├── 05_outputs/ ← entregas finais (versionadas)
└── 06_arquivo/ ← histórico fechado

Cada pasta tem propósito único. Claude segue o fluxo entrada → processamento → saída sem inventar.

2

📜 Regras de chão

3-5 regras inegociáveis evitam 90% dos acidentes. Cole no início de qualquer conversa de co-work:

Regras de chão (não-negociáveis):

1. Leia 00_sobre_mim/ antes de qualquer tarefa.
2. Nunca edite 01_templates/. Use como referência.
3. Sempre entregue em 05_outputs/ com timestamp ISO.
4. Confirme antes de apagar QUALQUER arquivo.
5. Ao final, escreva log em 04_processando/_log.md
3

📦 Skills da comunidade e marketplace

Mais de 100 skills disponíveis: oficiais da Anthropic + comunidade. Frontend, PDF, Excel, contabilidade, marketing, advertising. Não comece do zero — pesquise, instale, customize.

Onde achar: marketplace oficial da Anthropic · GitHub (search "claude skill") · X (busque "claude code skill") · Reddit r/ClaudeAI.

Regra de segurança: leia o markdown da skill antes de instalar. Verifique permissões pedidas. Prefira fontes oficiais e contas conhecidas.

4

🎯 5 exemplos reais de co-work

1. Organizar downloads

"Renomeie tudo em ~/Downloads pelo padrão {ano-mês-tipo-resumo}.ext. Mova pra subpastas por tipo. Não apague nada. Faça resumo do que mudou."

2. Relatório semanal a partir de planilhas

"Pega as 3 planilhas em 03_entradas/. Calcula MRR, churn e LTV. Gera Excel em 05_outputs/ com aba executiva + abas brutas."

3. Briefing pré-reunião

"Olha minha agenda das próximas 2h. Pra cada reunião com cliente, gera briefing de 1 página com histórico, pendências e perguntas-chave."

4. Deck a partir de notas

"Lê 03_entradas/notas-cliente-X.md. Cria deck de 8 slides em 05_outputs usando 01_templates/master-empresa.pptx."

5. Fluxo de atendimento

"Toda manhã, pega tickets novos do Slack #suporte. Cruza com FAQ em 01_templates. Gera respostas-rascunho em 04_processando."

5

⚠ Cuidados não-negociáveis

  • • Princípio do menor privilégio — dê só o que a tarefa precisa
  • • Backup antes de operação destrutiva — sempre
  • • Dry-run primeiro — peça pra Claude descrever sem executar
  • • Log obrigatório — pra revisão posterior
  • • Tarefas de baixo risco primeiro — confiança se constrói
6

✅ Sinais de domínio (e o teto)

Você domina o N3 quando:

  • • Tem 5+ skills próprias salvas
  • • Executa rituais semanais sem digitar contexto novo
  • • Entregou pelo menos 1 trabalho real pra cliente via co-work
  • • Confia em deixar Claude executar tarefas com baixo monitoramento

Teto: você precisa de git, sessões paralelas, plan mode, ou clientes pagando R$ 25k+. Aí é Claude Code (N4).

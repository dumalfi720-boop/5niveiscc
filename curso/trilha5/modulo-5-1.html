🛰 Claude como infraestrutura

Os 8 elementos que tiram Claude do "laptop ligado" e o colocam pra rodar 24/7 — routines, hooks, channels, headless, agent SDK, autodream.

1

☁ Routines em nuvem

Routines são configurações de Claude Code que rodam na infra da Anthropic — seu laptop fica desligado. É O salto qualitativo do N5: tudo no curso aponta pra esse momento.

Exemplo canônico: você dorme, alguém abre PR no seu repo, routine detecta, dispara revisão completa com comments inline, posta sumário no Slack. Quando acorda, está pronto pra mergear.

2

🔔 Triggers: cron, API, GitHub event

3 formas de acionar:

  • • Cron — "todo dia 8h", "toda segunda 9h", "primeiro do mês". Pra rituais previsíveis.
  • • API call (webhook) — chegada de webhook dispara. Pra integração com Stripe, Zapier, Make, n8n.
  • • GitHub event — PR aberto, issue criada, comentário com /command. Direto na sua dev pipeline.
3

🛡 Hooks como trilhos de segurança

Lógica custom em pontos do ciclo de vida. Os 4 tipos mais úteis:

pre-tool-use

Bloqueia comando perigoso antes dele rodar (ex: rm -rf, drop table, force push em main).

post-edit

Auto-format, lint, type-check em todo arquivo que Claude tocar.

stop

Notifica Slack/email quando sessão longa termina.

response

Som/badge a cada resposta. Útil em remote control.

Hooks são o que separa "demo bonita" de "infra confiável".

4

📡 Channels: Slack, Discord, Telegram, iMessage, webhook

Dois sabores de channel:

  • • 1-way (evento → Claude): calendário marca reunião, Claude prepara briefing. CI quebra, Claude analisa logs. Cliente abre ticket, Claude triagem.
  • • 2-way (humano ↔ Claude): você texta do celular "fix bug X". Claude opera no codebase remoto e responde quando termina.
5

🤖 Headless mode (claude -p)

Claude Code roda sem TTY humano: claude -p "faz X". Saída vai pro stdout. Pipe-friendly: canaliza pra Slack, Datadog, outro agente, qualquer coisa.

É o que viabiliza Claude como peça componível em sistemas maiores. Sem ele, Claude fica preso ao loop interativo.

6

📚 Agent SDK — virar builder, não só user

Bibliotecas oficiais em Python e TypeScript pra construir seu próprio produto sobre o engine do Claude Code. Tools customizadas, streaming, embed em SaaS.

É a saída pra quem quer produto SaaS em vez de só consultoria. Você para de vender automação e começa a vender software.

7

📱 Remote control — celular como remote do PC

/remote-control conecta sessão local ao app mobile do Claude. QR code ou link. Você sai pra caminhar com o cachorro e continua "operando" do iPhone — a sessão segue rodando no Mac.

Trabalho parou de ter "lugar". O laptop vira servidor; o celular é só interface.

8

💤 Autodream — consolidação de memória

Subagente em background que entre sessões: apaga fatos contraditos, mescla duplicados, converte "ontem" pra datas absolutas. Como humano que sonha pra consolidar memória.

Sem isso, a memória drifta após 3-6 meses. Com isso, Claude fica afiado por muito mais tempo. Detalhe importante: você precisa ativar manualmente.

🛰 Claude as infrastructure

The 8 elements that take Claude away from the "laptop on" and get him running 24/7 — routines, hooks, channels, headless, agent SDK, autodream.

1

☁ Cloud routines

Routines are Claude Code configurations that runon the Anthropic infrastructure— your laptop turns off. It's N5's qualitative leap: everything on the course points to this moment.

Canonical example: you sleep, someone opens PR in your repo, routine detects it, triggers full review with inline comments, posts summary on Slack. When it wakes up, it's ready to merge.

2

🔔 Triggers: cron, API, GitHub event

3 ways to activate:

  • • Cron— "every day 8am", "every Monday 9am", "first of the month". For predictable rituals.
  • • API call (webhook)— webhook arrival triggers. For integration with Stripe, Zapier, Make, n8n.
  • • GitHub event— PR opened, issue created, comment with /command. Directly into your dev pipeline.
3

🛡 Hooks as safety rails

Custom logic at points in the life cycle. The 4 most useful types:

pre-tool-use

Blocks dangerous commands before they run (e.g. rm -rf, drop table, force push in main).

post-edit

Auto-format, lint, type-check every file Claude touches.

stop

Notifies Slack/email when long session ends.

response

Sound/badge for each answer. Useful in remote control.

Hooks are what separates "pretty demo" from "infra-trusted".

4

📡 Channels: Slack, Discord, Telegram, iMessage, webhook

Two channel flavors:

  • • 1-way (event → Claude):calendar marks meeting, Claude prepares briefing. CI breaks, Claude analyzes logs. Customer opens ticket, Claude triages.
  • • 2-way (human ↔ Claude):you text from your cell phone "fix bug X". Claude operates on the remote codebase and responds when finished.
5

🤖 Headless mode (claude -p)

Claude Code runs without human TTY:claude -p "faz X". Output goes to stdout. Pipe-friendly: pipes to Slack, Datadog, another agent, anything.

This is what makes Claude viable as a composable part in larger systems. Without it, Claude is stuck in the interactive loop.

6

📚 Agent SDK — become a builder, not just a user

Official libraries in Python and TypeScript to build your own product based on the Claude Code engine. Customized tools, streaming, embedded in SaaS.

It's the solution for those who want a SaaS product instead of just consultancy. You stop selling automation and start selling software.

7

📱 Remote control — cell phone as a PC remote

/remote-controlconnects local session to Claude's mobile app. QR code or link. You go out for a walk with the dog and continue "operating" from the iPhone — the session continues running on the Mac.

Work stopped having a “place”. The laptop becomes a server; the cell phone is just an interface.

8

💤 Autodream — memory consolidation

Background subagent that between sessions: deletes contradicting facts, merges duplicates, converts "yesterday" to absolute dates. As a human who dreams to consolidate memory.

Without this, memory drifts after 3-6 months. This means Claude stays sharp for much longer. Important detail: you needactivate manually.

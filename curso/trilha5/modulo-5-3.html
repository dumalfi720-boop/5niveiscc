💼 O que vender e como descobrir o que já existe

A skill de maior alavancagem do N5 não é construir do zero — é descobrir o que a comunidade já fez e adaptar pro contexto do cliente.

1

📚 Catálogo da comunidade (5k+ skills, 800+ MCPs, 3k+ marketplaces)

Em maio/2026 o ecossistema já tem mais de 5.000 skills publicadas, 800+ MCP servers, 3.000+ marketplaces de plugins. Maioria open-source, muita coisa madura.

Quem entra no N5 achando que precisa criar tudo do zero está jogando 80% do tempo fora. Quem garimpa primeiro entrega cliente em 1 semana em vez de 1 mês.

2

🔍 Onde garimpar

  • • Marketplace oficial Anthropic — categorizado, verificado, seguro
  • • GitHub — busque "awesome-claude-code", "awesome-claude-skills"
  • • X (Twitter) — "claude code skill" + sua vertical (devops/sales/finance/legal)
  • • Reddit — r/ClaudeAI, r/LocalLLaMA têm threads de implementações reais
  • • Marketplaces verticais — alguns só de devops, outros só de sales, etc.
3

🔧 Como adaptar OSS sem virar refém

Disciplina pra não ficar preso à versão antiga:

  1. 1. Fork antes de mexer — não edite o original
  2. 2. Documente cada customização em CHANGELOG.md local
  3. 3. Rebase periódico do upstream (mensal) — pega atualizações
  4. 4. Contribua patches de volta quando faz sentido genérico
  5. 5. Se a customização vira maior que o original, é sinal de criar do zero
4

💼 Ofertas vendáveis no Nível 5

Revisão de PR 24/7 — R$ 8-15k/mês

SLA: comments em PR em <30min após abrir. Substitui parte do code review humano.

Triagem automática de backlog — R$ 5-12k/mês

Issues entram, Claude categoriza, prioriza, anexa contexto e atribui.

Auditoria semanal — R$ 6-10k/mês

Segurança, qualidade de código, dívida técnica, dependências.

Briefing pré-call de cliente — R$ 4-8k/mês

Pra times de vendas/CS: cada reunião com cliente vem com briefing antes.

Relatório autônomo — R$ 3-7k/mês

Semanal/mensal — métricas operacionais consolidadas pra diretoria.

Monitor de competidores — R$ 2-5k/mês

Lê site/redes/PRs dos concorrentes, alerta sobre lançamentos.

Posicione como infraestrutura, não como "agente de IA". SLA mensurável, recurring revenue, setup + manutenção.

5

⚠ Erros que destroem confiança do cliente

❌ Habilitar rotina sem dry-run

Cliente vê primeiro bug, perde fé.

❌ Vender autonomia em tarefa criativa

Copywriting / posicionamento NÃO automatize.

❌ Sem monitor de logs

Drift silencioso destrói qualidade.

❌ SLA sem alçada

"24/7" sem definir o que escala pra humano vira problema.

❌ Ignorar custo de tokens

Margem some sem você perceber.

❌ Entregar sem runbook

Cliente fica sem saber operar quando você sumir.

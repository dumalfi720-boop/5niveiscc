📁 Projects, Memory and Connectors

The 8 features that transform stateless chat into a tool with real continuity. Whoever masters these 8 saves 5 hours/week with Claude paying for himself.

1

🔄 The big change: chat with continuity

Imagine: you open a new conversation on Tuesday within a project and ask "what did we decide about the Q2 release last week?". Claude researches the history, quotes the conversation, and continues from there. It's no longer a stateless tool — it's something with continuity.

The difference with N1 is qualitative. In N1 you paste context every time. In N2 the context lives in the project. You only say what changed.

💡 Domain Signal:You never paste the same brief twice again — because it lives in the project, and Claude reads it himself with each new conversation.

2

🧠 Memory + search in previous conversations

Two distinct features that combine:

Memory (free, on all plans)

Claude remembers facts about you between conversations: your role, preferences, decisions. Say "remember that I prefer answers in bullets" and that will apply forever.

Search in previous conversations (paid)

You search for a text excerpt and Claude retrieves the exact conversation, with a link. Combines with project knowledge base to eliminate “starting from scratch”.

3

🔌 Native Connectors (50+)

Top 6 that cover 80% of cases:

Slack

"Summarize #sales threads from the last 7 days"

Google Drive

"Get the latest spec doc and give me the open points"

Gmail

"Unanswered emails from customer X this week"

GitHub

"Issues open in repo Y with bug tag"

Notion

"Current status of project Z"

Calendar

"What's on my agenda Thursday?"

🔐 Security:OAuth connectors are read-only by default. You give granular permission by scope. You can revoke it at any time in the settings.

4

📊 Real file creation

Four formats available to everyone (including free):

  • • .xlsx— Excel with functional formulas, pivot tables, conditional formatting
  • • .pptx— PowerPoint that respects brand master (paste 1 example slide)
  • • .docx— Word with styles, table of contents, tables
  • • .pdf— direct export with clean layout

Chat stops being a brainstorm and becomes a delivery factory. You say "generate a deck of 8 slides summarizing this" — and download the .pptx ready to send to the client.

5

🎨 Artifacts with persistent storage

Artifacts are interactive mini-apps in the side panel. Now with 2 new capabilities:

Persistent storage

Data remains between sessions. You create a feedback tracker today, open it tomorrow, the data is there.

Built-in Claude API key

The artifact can call the API directly — it "thinks" on its own, without you intermediating.

Public link

Publish and send to the team. They open it in the browser, use it, without registering.

Result: you (without code) create a tool for a client in 10 minutes, send them the link, they use it. It's the era of "talk delivers product".

6

📈 Inline visuals (charts, diagrams)

Different from artifacts: alive within the chat, ephemeral, without becoming an archive. They are used for quick thinking.

Use when: you want to compare 2 options, validate a hypothesis, or explain a concept that the text doesn't cover well. Paste a CSV and ask for "bar chart grouped by month". Click and switch to line. Ask "now compare to last year".

Don't use it when: you need the graphic outside the chat — then use file creation.

7

📑 Microsoft Office Add-ins

Pro+: Claude lives inside Excel, PowerPoint and Word as a native add-in. It's not Claude reading the file — it's Claude operating the app.

  • • Excel:reads multi-tab workbook, explains formulas with cell-level citation, edits while preserving all dependencies
  • • Power point:reads your master, your fonts, your colors — generates slides that look like they were made to the brand’s standard
  • • Word:respects styles, summary, caption formatting and references
  • • Cross context (April/2026):analysis in Excel becomes a deck in PPT in the sequence

If your day is Office, this is N2's point of impact.

8

💳 Free vs Pro: what’s worth upgrading

Free delivery

  • • Memory
  • • File creation
  • • Inline visuals
  • • Projects (limited)
  • • Some connectors

Pro unlocks

  • • Search old chats
  • • Persistent artifacts
  • • Office add-ins
  • • More use of Opus
  • • All connectors

Strategy: test 1 week free with the basics. If you hit the ceiling, go up to Pro. Pro pays for itself in ~2 weeks for heavy users.

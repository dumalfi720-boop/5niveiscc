2.1~30 min

📁 Projects, Memory and Connectors

The 8 features that transform chat into real productivity.

What is it:

You open a new conversation and ask "what did we decide about Q2?". Claude jumps through the memory and history of the project, cites the previous conversation and continues from there.

Why learn:

Kills the "start from scratch every time" problem. The compounded time gain from this alone justifies the Pro.

Key concepts:

State between conversations · Automatic citation · Memory + search · Project as container.

What is it:

Memory: Claude remembers facts about you (role, preferences, decisions) between conversations. Chat search: you search through the text and Claude retrieves the exact conversation.

Why learn:

Kills "starting from scratch". Memory is free on all plans; the search is paid but it's worth it.

Key concepts:

Memory toggle in settings · "Remember that I prefer X" · Semantic search · Match with project knowledge.

What is it:

50+ connectors via OAuth. "+" button in chat → choose tool → log in → done. You ask "summarize my #sales threads for the week" and Claude searches.

Why learn:

Kill copy-and-paste. This shortcut alone is where 60% of N2's time savings go.

Key concepts:

Secure OAuth · Granular permissions · Read-only by default · Combine connectors in the same response.

What is it:

Claude generates real files — Excel with functional formulas, PPT, Word, PDF. You download it and send it to the customer. It's not a "preview" — it's deliverable.

Why learn:

Chat stops being a brainstorm and becomes a delivery factory. Available to everyone, including free.

Key concepts:

.xlsx, .pptx, .docx, .pdf · Formulas that work · Pivot tables · Brand style by example upload.

What is it:

Interactive mini-apps on the side panel, now with storage that persists between sessions. You can call Claude's API. Publishable with public link.

Why learn:

You create a feedback tracker or calculator for customers in 10 minutes without code. Conversation delivery tool.

Key concepts:

React component sandbox · Cross-session storage · Built-in API key · Shareable public link.

What is it:

When a graphic explains better than text, Claude draws within the conversation. You click, change the type, ask for other variables — update live.

Why learn:

Different from artifacts: living, ephemeral, without becoming an archive. They are used for reasoning and quick validation. Free for everyone.

Key concepts:

CSV drop · Side-by-side comparison · Change chart type · Does not become a file (use file creation for this).

What is it:

Claude lives inside Excel, PowerPoint and Word. Reads the multi-tab workbook, cites cells, edits while preserving dependencies. PPT follows brand master, fonts, layouts. In April/2026, context shared between the 3.

Why learn:

If your day is Office, this is THE point of impact. Analysis in Excel becomes a deck in a direct PPT.

Key concepts:

Native add-in · Automatic brand master · Cell-level citation · Cross-app context (Pro+).

What is it:

Free: memory, file creation, inline visuals. Pro: search in old chats, persistent artifacts, Office add-ins, more use of Opus.

Why learn:

Knowing what's free prevents premature upgrades. Knowing what is paid for avoids the frustration of “not having it”.

Key concepts:

Try 1 week free · Upgrade to Pro only when you hit the ceiling · Pro pays for itself in ~2 weeks if you are a heavy user.

2.2~20 min

🚀 Cheat Code: stop copying and pasting

The habit that prepares the jump to Level 3.

What is it:

For 5 days, write down every time you copied something from another tool to Claude (and vice versa). It's the spreadsheet that reveals where the connectors will save you the most.

Why learn:

Without a map, you install connectors for fashion. With map, you install where time really bleeds.

Key concepts:

Column: source → destination → frequency · Top 3 become connectors · Rest remains pure chat.

What is it:

Recipe: 1 project with fixed instructions + 1-2 active connectors + 1 standard prompt that you re-execute every week ("summary for the week, actions for next").

Why learn:

It's the N2's "real productivity" standard. It is repeated in any area.

Key concepts:

1 project = 1 weekly ritual · Standard prompt saved in the project · Connector reads source · Output to file.

What is it:

3 ready-made assemblies: (1) Content project with Drive+Notion, (2) Service project with Slack+Gmail, (3) Study project with Drive+Calendar.

Why learn:

You copy one of the 3 and adapt it. You don't need to start from scratch.

Key concepts:

Case 1: Instagram script · Case 2: support screening · Case 3: review for the competition.

What is it:

Too generic project · no docs attached · no fixed instructions · mixing 3 subjects in the same project · not reviewing results.

Why learn:

Each error costs 1h/week. Avoid the 5 = gain 5h.

Key concepts:

"1 project = 1 scope" is a rule of thumb · Docs in 1st week · Instruction is the base, not the ceiling.

What is it:

There comes a time when you want Claude to organize your folder, edit local files, execute a sequence without you copying. This is the N2 ceiling — N3 begins.

Why learn:

Recognizing the signal avoids "squeezing the N2". The co-working journey starts here.

Key concepts:

Filesystem access · Isolated VM · Desktop app + co-work tab · Granular permissions.

What is it:

Before enabling co-work, organize your work folder: "about-me", "templates", "projects", "outputs" folders. This prepares Claude to work with clear rules.

Why learn:

Co-work with structure is coworking. Without structure, VA is unpredictable.

Key concepts:

Minimum structure · "Never edit templates" · "Always delivered in outputs" · 100% manual pre-work.

🎬 Of the 247 messed up responses to the Artifact ritual

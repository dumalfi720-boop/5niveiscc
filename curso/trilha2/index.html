Mata o problema "começar do zero toda vez". O ganho de tempo composto disso, sozinho, justifica o Pro.

🚀 Cheat Code: parar de copiar e colar

O hábito que prepara o pulo pro Nível 3.

O que é:

Por 5 dias, anote toda vez que você copiou algo de outra ferramenta pro Claude (e vice-versa). É a planilha que revela onde os conectores vão te poupar mais.

Por que aprender:

Sem mapa, você instala conectores por moda. Com mapa, você instala onde realmente sangra tempo.

Conceitos-chave:

Coluna: fonte → destino → frequência · Top 3 viram conectores · Resto fica chat puro.

O que é:

Receita: 1 projeto com instrução fixa + 1-2 conectores ativos + 1 prompt-padrão que você re-executa toda semana ("resumo da semana, ações pra próxima").

Por que aprender:

É o padrão "produtividade real" do N2. Repete-se em qualquer área.

Conceitos-chave:

1 projeto = 1 ritual semanal · Prompt-padrão salvo no projeto · Conector lê fonte · Saída em arquivo.

O que é:

3 montagens prontas: (1) Projeto de conteúdo c/ Drive+Notion, (2) Projeto de atendimento c/ Slack+Gmail, (3) Projeto de estudos c/ Drive+Calendar.

Por que aprender:

Você copia uma das 3 e adapta. Não precisa começar do zero.

Conceitos-chave:

Caso 1: roteiro Instagram · Caso 2: triagem suporte · Caso 3: revisão pra concurso.

O que é:

Projeto genérico demais · sem docs anexados · sem instrução fixa · misturar 3 assuntos no mesmo projeto · não revisar resultados.

Por que aprender:

Cada erro custa 1h/semana. Evitar os 5 = ganhar 5h.

Conceitos-chave:

"1 projeto = 1 escopo" é regra de ouro · Docs em 1ª semana · Instrução é a base, não o teto.

O que é:

Chega o momento em que você quer que Claude organize uma pasta sua, edite arquivos locais, execute uma sequência sem você ficar copiando. Isso é teto de N2 — começa o N3.

Por que aprender:

Reconhecer o sinal evita ficar "espremendo o N2". A jornada do co-work começa aqui.

Conceitos-chave:

Filesystem access · VM isolada · Desktop app + co-work tab · Permissões granulares.

O que é:

Antes de habilitar co-work, organize sua pasta de trabalho: pastas "about-me", "templates", "projetos", "outputs". Isso prepara o Claude pra trabalhar com regras claras.

Por que aprender:

Co-work com estrutura é coworker. Sem estrutura é VA imprevisível.

Conceitos-chave:

Estrutura mínima · "Nunca edite templates" · "Sempre entregue em outputs" · Pré-trabalho 100% manual.

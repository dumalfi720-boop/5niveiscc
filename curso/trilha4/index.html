4.1~30 min

⚙ Claude Code: the engine

The 8 core elements of those who work with Claude Code every day.

What is it:

Claude Code runs as a CLI in the terminal or as a Code tab in Claude Desktop. Same engine, different interface. Terminal is faster once you get used to it.

Why learn:

You don't need to be a fluent terminal dev — start with the Code tab, progress when you want speed.

Key concepts:

CLI · Desktop · Same model · Same features · Optional learning curve.

What is it:

Markdown in the project root. Claude reads in every conversation: stack, conventions, paper, rules. Rule of thumb: ≤200 lines. Use @arquivo for details only when necessary.

Why learn:

This is what separates N4 from N3. Without this, Claude reinvents conventions with each session.

Key concepts:

Stack · Conventions · Role · Rules · @ for details · Update when you make mistakes.

What is it:

When Claude makes a mistake, say "update claude.md so you don't do this again". Anthropic itself does this. Within weeks, the archive trains Claude in his ways.

Why learn:

It is the loop that separates average N4 from dominant N4.

Key concepts:

Error = opportunity · Written rule > spoken rule · Controlled version · Share in the team.

What is it:

Shift+Tab 2x activates plan mode: Claude reads the code, presents a plan, waits for approval. Opus Plan: Opus plans, Sonnet executes. Half the cost, equal quality.

Why learn:

Approve explicit plan reduces refactors. Opus Plan is the most underrated cost shortcut.

Key concepts:

Plan before code · Human approval · Opus to plan · Sonnet to execute.

What is it:

Claudes specialized for specific jobs: one for testing, one for security, one for docs. Each one runs in its own context — noise from one does not pollute the other.

Why learn:

You assemble an "engineering team" with experts. Multiples in parallel.

Key concepts:

Isolated context · Specialist by role · Communication via main session · They do not talk directly.

What is it:

claude-worktree feature-name creates branch-isolated git workspace. Open another terminal and run another one. 3-4 parallel sessions without file conflict.

Why learn:

It's how Boris Cherny (creator of Claude Code) works: 5 sessions minimum every day.

Key concepts:

Isolated git workspace · Own branch · No conflict · Sweet spot 3-4.

What is it:

Model Context Protocol connects external tools. But the rule (from Anthropic itself) is: CLI first, REST endpoints second, skills next, MCP only when nothing else fits. CLI spends 60-70% less tokens.

Why learn:

Anyone who ignores this hierarchy pays 3x more in tokens and quickly loses context.

Key concepts:

CLI tools (gh, aws, gcloud) · REST APIs · Skills · MCP last.

What is it:

Feature from January/2026: when MCP exceeds 10% of the context, Claude defers loading tools until needed. Reduces overhead by 85%, zero configuration.

Why learn:

Those who use MCP need to understand this — it is the feature that makes MCP viable in long sessions.

Key concepts:

10% trigger · Automatic tool search · Loading on demand · More MCP without paying context.

🚀 High-impact movements

The 8 habits that distinguish casual users from power users.

What is it:

/compact summarizes the old history into a tight summary (run proactively, don't wait for the warning). /context shows where your tokens are going. Combined with prompt caching: -60-90% cost on long sessions.

Why learn:

1M window in Opus 4.7 still gets sloppy after 50%. Those who control, pay less and maintain quality.

Key concepts:

/compact proactive · /context for debug · Automatic caching prompt · 50% is the trigger.

What is it:

Shift+Tab cycles to auto mode: safe commands go through classifier instead of asking for approval. /focus hides intermediates, shows only the final result.

Why learn:

Stopping pressing "yes" 30x per session frees you up to truly run parallel.

Key concepts:

Auto mode · Security classifier · /focus · Switch between sessions.

What is it:

Boris Cherny says that this is the most important habit of N4: give Claude a way to check his own work (Chrome extension to open browser, screenshot, run tests) and iterate until PASS.

Why learn:

Boris says he doubles or triples the quality of the output.

Key concepts:

Self-test · Chrome extension · Screenshots · Don't call me before PASS.

What is it:

If you typed the same prompt twice, turn it into a slash command. Boris uses /commit-push-pr dozens of times a day. They live at .claude/commands/.

Why learn:

Each slash is a personal macro. Multiply by 20 — your productivity explodes.

Key concepts:

.claude/commands/ · Shareable with team · Versioned in git · /commit-push-pr classic.

What is it:

/rewind (or Esc Esc) discards failed attempt without polluting context. /btw lets you ask a parallel question without breaking the flow. /branch (formerly /fork) forks the conversation to test different paths.

Why learn:

They are "version control" of the reasoning. Pairs perfectly with worktrees.

Key concepts:

Rewind = clear failure BTW = side doubt Branch = experiment.

What is it:

Reads your last month of use and generates reports: repetitive patterns, token spending, candidate prompts to become skills, rules to add to claude.md.

Why learn:

Most do not have information about their own use. Runs 1x/month, becomes an improvement map.

Key concepts:

Personal audit · Standards · Skill candidates · Claude.md rules emerge.

What is it:

/output style new changes Claude Code's "personality". Built-ins: default, explanatory, learning. Custom: code reviewer mode, no-fluff, documentation writer.

Why learn:

Same tool covers 10 different papers without mixing.

Key concepts:

Built-in vs custom · By design · Hot swappable style.

What is it:

N4 PRs bring: context of the problem, executed plan, files changed with reason, evidence of tests/checks, known risks. PR Standard is part of claude.md.

Why learn:

Good PR is the difference between a customer who pays R$25k and a customer who becomes a repeat customer.

Key concepts:

PR template on claude.md · Test evidence · Listed risks · Review by subagent.

🚀 Cheat Code: stop drooling Claude

The transition from N4 to N5 is mental, not technical.

What is it:

Most in N4 become nannies: they start sessions and watch each one. Identify 3 tasks that you do manually although they could be slash command, skill or hook.

Why learn:

Nanny is the bottleneck. Get out of the bottleneck = go up to N5.

Key concepts:

Audit 1 week · 3 babysitting tasks · Each one becomes automation.

What is it:

Repetitive task: slash command. Complex workflow: skill. Automatic validation at a specific moment: hook (pre-N5). Each of the 3 babysitting tasks becomes one of these.

Why learn:

Choosing the right abstraction = easy maintenance.

Key concepts:

Slash = shortcut · Skill = workflow · Hook = automatic trigger.

What is it:

Manage parallel on the nail · don't use plan mode · skip check · giant claude.md · ignore /insights · MCP-first instead of CLI-first.

Why learn:

Every mistake is an invisible ceiling. Falling into 2-3 of them = you spent 1 year without evolving.

Key concepts:

Management ≠ nanny · Plan mode default · Mandatory check · CLI before MCP.

What is it:

You feel like "this could run every day for 8 hours without me having to open the laptop". It's the ceiling of N4 — N5 (cloud routines) comes in.

Why learn:

Recognizing it avoids "squeezing N4" and taking a long time to climb.

Key concepts:

Routine vs session · No machine · 24/7 · Sleep-friendly.

What is it:

N4 delivers real systems — not isolated automation. Charge by value: the client pays R$50k because the feature unlocks R$500k/year in revenue or saves 2000 hours of staff time.

Why learn:

This is where freelance becomes a sustainable agency.

Key concepts:

Explicit ROI · Closed scope · Monthly maintenance · Customer who understands value.

What is it:

Before enabling N5: choose 1 very low-risk routine (daily summary that comes only for you). 5x hand wheel. If you pass 5, schedule. Trust is built, not assumed.

Why learn:

Skipping this step = automation that destroys trust in the 1st bug.

Key concepts:

Low risk first · Manual before cron · 5 rounds minimum · Only you as the recipient.

MODULE 4.2 · ~30 min

🚀 High-impact movements

The 8 habits that separate casual users from power users. Those who master the 8 charge R$25k+ per project with ease.

1

📐 Context window master

1M window on Opus 4.7 still looks "sloppy" after 50% usage. Two commands resolve:

  • • /compact— summarizes past history in tight summary.Rotate proactively, not when the warning appears (it's too late).
  • • /context— shows where your tokens are. Identifies villains: long file, MCP overhead, inflated history.

Combined with prompt caching (automatic in Claude Code): 60-90% reduction in long sessions.

2

⚡ Auto mode + /focus

Auto mode:Shift+Tab cycles between manual/auto. In auto, safe commands go through the internal classifier instead of asking for "yes" at each step./focus:hides the intermediate steps, shows only the final result.

Both together: you trigger a session, switch to another worktree, come back when it ends. It's exactly like Boris runs 5 parallels every day.

3

🔍 Verification loop — Claude tests his own work

Boris Cherny says:"It's the most important N4 habit."Give Claude a way to check what he delivers:

  • • Pair Claude Code with Chrome extension — it opens the browser, tests the UI, iterates
  • • Ask for screenshots of the feature working
  • • "Don't call me until the tests pass"
  • • Define explicit success criteria before starting

Boris says this habit alone 2-3x the quality of the output.

4

⌨ Custom slash commands

If you typed the same prompt twice, use slash command. Live in.claude/commands/:

.claude/commands/commit-push-pr.md:

Run the tests. If they pass:
1. git add .
2. git commit with message using project convention
3. git push -u origin HEAD
4. gh pr create with default template
5. Paste the PR link

Boris uses /commit-push-pr dozens of times/day. Commands can be shared (versioned in git) with the entire team.

5

🔄 /rewind, /btw, /branch — git for conversation

/rewind(or Esc Esc) — discards failed attempt completely, without leaving corrections polluting the context. Returns to a previous clean message.
/btw— asks a parallel question (“what does this function actually do?”) without breaking the main flow.
/branch— the conversation forks at an exact point. Test path A, come back, test B. It's git for reasoning. It pairs perfectly with worktrees: one for files, one for thoughts.
6

📊 /insights — monthly report on your usage

Underrated command: reads your last month and generates report with patterns, token spending, prompts you repeated and candidate rules to enter claude.md.

Rotate 1x/month. Turns into a personalized improvement map. You discover:"I rewrote this instruction 12 times in 4 weeks — it should be skill".

7

🎭 Output styles — 10 jobs with the same Claude

/output-style newcreates new personality. Built-ins: default, explanatory, learning. Common Custom:code reviewer mode, no-fluff, docs writer, juniors-friendly.

Same tool covers 10 different papers without mixing. Useful when the same project requires output formatted for different audiences.

8

🔀 Better PRs and systematic review

PR N4 carries:context of the problem, plan executed, files changed with reason, evidence of testing, known risks. This pattern must be in claude.md.

Use "code-reviewer" sub-agent for automatic review before asking for human review. Result: PR arrives with self-criticism and main issues mitigated.

It's what separates "Claude Code did code" from "Claude Code did engineering." Premium customer sees and pays.

MÓDULO 4.3 · CHEAT CODE · ~20 min

🚀 Cheat Code: parar de babar Claude

O salto de N4 pra N5 é mental, não técnico. A maioria fica trancada porque continua "olhando" Claude — esse módulo te ensina a soltar.

1

🍼 Identificar o que você ainda faz "olhando"

Power-users do N4 caem numa armadilha curiosa: viram babá das próprias sessões paralelas. Dispara 4 sessões, fica alternando entre elas, comenta cada passo. Isso é babá com extra steps.

Faça auditoria de 1 semana. Liste 3 tarefas que você "fez à mão" embora pudessem ser slash command, skill, hook ou rotina. Essas 3 são suas primeiras candidatas a virar autônomas.

2

🔧 Transformar em comando, skill ou hook

Cada candidata vai pra uma das 3 caixas:

Slash command — quando é um atalho de prompt

Ex: /commit-push-pr, /update-deps, /sync-types

Skill — quando é workflow com passos

Ex: relatorio-semanal-cliente, triagem-bug, gerar-deck-vendas

Hook — quando é validação automática num momento

Ex: pre-tool-use (bloquear rm -rf), post-edit (formatar), stop (notificar Slack). Hooks são teaser do N5.

3

⚠ Erros típicos do Nível 4

❌ Gerenciar paralelo na unha

Alternar entre sessões manualmente em vez de deixar /focus + auto trabalhar.

❌ Pular plan mode

Sair direto pra execução — gera refactor caro.

❌ Sem verificação

Aceitar primeira saída sem self-test.

❌ claude.md gigante

>200 linhas dispara tokens em toda sessão.

❌ Ignorar /insights

Sem audit = sem evolução.

❌ MCP-first

Esquecer CLI > MCP. Paga 3x em tokens.

4

🚨 Sinal do teto: "queria que rodasse sem eu estar aqui"

Você está rodando /schedule + worktrees + subagentes — mas precisa que seu laptop esteja ligado pra tudo isso. Aí pensa: "se ele só pudesse rodar a revisão diária de PRs sem eu estar online…"

Isso é o teto exato do N4. Resposta: rotinas em nuvem (N5). Não tem como furar — sobe.

5

💼 Como cobrar projetos R$ 25-75k

N4 não vende automação isolada — vende sistema. Posicione assim:

  • • Diagnóstico (R$ 5-10k): mapeia gargalos, propõe sistema. Standalone, gera proposta da próxima fase.
  • • Implementação (R$ 25-50k): entrega sistema com claude.md, skills, slash commands, runbook, treino.
  • • Manutenção (R$ 3-8k/mês): /insights mensal, ajustes, novas features.

ROI explícito: "vou poupar 2000h/ano da sua equipe, valor X. Cobro 10%." Cliente que entende ROI paga sem desconto.

6

📋 Preparando rotina simples pro Nível 5

Antes de habilitar rotinas em nuvem, faça pré-trabalho:

  1. 1. Escolha 1 rotina baixíssimo risco. Apenas pra você, não pro cliente, não externa. Ex: "resumo do que rolou no GitHub do meu time, todo dia 9h".
  2. 2. Execute manualmente por 5 dias. Refine output até estar satisfeito.
  3. 3. Documente prompt, entrada e saída esperada.
  4. 4. Defina kill switch: "se output passar de X tokens, falhe e me avise".
  5. 5. Só agora vire rotina (N5).

Confiança se constrói gradualmente. Pular = automação que destrói confiança no 1º bug.
